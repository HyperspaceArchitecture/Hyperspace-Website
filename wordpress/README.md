# WordPress test package

`hyperspace-architecture-theme.zip` is the installable test theme.

The uncompressed source is in `hyperspace-architecture/`. It is generated from
the same project and discipline data used by the master site, so the homepage,
wide project matrix, discipline pages, brand assets and image alternative text
stay aligned.

This first WordPress package is for staging and compatibility testing. Do not
replace the current public domain until the redirect map, analytics, forms,
permalinks, image ownership, structured data and search indexing have been
checked.
